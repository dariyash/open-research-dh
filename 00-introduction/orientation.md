# Orientation and How to Use the Course

This page explains how the course is organised and how to work through it.

This is a **self-paced, learning-by-doing** course. Short explanations are followed immediately by
hands-on work with real cultural-heritage data. You can follow it in two ways:

- **Beginner path**: use the prepared Van Gogh example, datasets, and code as they are.
- **Own-project path**: apply every step to *your own* dataset and research question. The notebooks
 are written so you can re-point them at your own data by editing a single configuration cell.

## What you need before you start
- A laptop (Windows, macOS, or Linux), no special hardware.
- **Anaconda Navigator** (free) for Python, Jupyter Notebook and JupyterLab, installed in Module 3.
- A free **GitHub** account, created in Module 3.
- Free API keys where noted (e.g. **Europeana**), the notebooks also run without them, using shipped samples.
- No prior coding experience is required. Where code appears, we generate it with AI and learn to **check** it.

## How the modules fit together
The course has eight modules plus an introduction and a wrap-up. It follows one research arc from
start to finish:

1. **Open Humanities**, why openness, and what it means in the humanities.
2. **Open Data**, find and assess heritage datasets · *notebook: obtain a dataset*.
3. **Documentation & GitHub**, document as you go; version control · *video*.
4. **Documenting AI**, prompt, check, and record AI use · *notebook: filter a dataset*.
5. **Data Analysis**, clean, analyse, visualise, narrate · *notebook: analyse*.
6. **Data Enhancement** *(optional)*, enrich with Wikidata.
7. **Reproducible Research**, audit against the TIER protocol.
8. **Open Publishing**, publish openly on Zenodo; FAIR · *video*.

The three hands-on notebooks share **one dataset** and run in order:
**Module 2 (obtain) > Module 4 (filter) > Module 5 (analyse).**

Each module ends with a short task and a self-check.
